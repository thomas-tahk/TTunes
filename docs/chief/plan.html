TTunes Build Plan

Your personal always-on station, from the June spec you confirmed today. Four milestones, each something you can open and use. Only Milestone 1 is broken into issues; the rest get broken down when they're next.

Project done-gate: I open TTunes on my phone, music is already playing within a second, and I bulk-drop a folder that the AI librarian tags and files so I can play-now any track from it.

Approve with these four calls

  1. Phones block sound until you tap once. Every mobile browser does this; no app can get around it. I'll read the gate as "one tap, music within a second, picking up where you left off." Say if that's not acceptable.
  2. An always-on host costs about $5/month. Free tiers sleep, and a sleeping server breaks "within a second." My pick is Railway or Fly.io; chief checks current pricing in M1 and picks the cheaper one that never sleeps. Audio sits on Cloudflare R2 (10 GB free) and data on Neon Postgres (free, wakes in under a second).
  3. One owner password. The URL is public, so a single password protects it. No accounts, because it's just for you.
  4. You create three accounts when M1 gets to deploy: Cloudflare R2 bucket, Neon database, host. Chief hands you a step-by-step wizard at that point; agents build everything before then without them.

Milestones

DONE · June

M0 · Local MVP

Upload, instant shuffle, next-track prefetch, play-now, queue, delete. Runs on your laptop only.

NEXT

M1 · On my phone, from the cloud

Same player, live on a URL, audio in R2, catalog in Postgres, and the station remembers what was playing so any device picks it up.

Gate: I upload a song on my laptop, close it, open TTunes on my phone, tap once, and the station resumes within a second.

THEN

M2 · Bulk add + AI librarian

Drop a folder of hundreds. Each file is identified (embedded tags → AcoustID/MusicBrainz fingerprint → Claude), tagged and filed. Only strong "same song?" matches ask you, all in one pass. Every tag stays editable.

Gate: the project done-gate.

THEN

M3 · Versions, channels, playlists

Group versions of a song under one primary so shuffle doesn't repeat them. Smart channels from tags ("90s", "live") and hand-built playlists you can switch the station to.

Gate: I switch the station to a "live recordings" channel and it never plays two versions of the same song in a row.

LATER

M4 · Acquire

Ask for a track; the librarian finds a legit place to buy it, or extracts audio once from a web link into your library (personal use only, per spec §11).

Gate: I ask for a song I don't own and end up playing it from my library.
