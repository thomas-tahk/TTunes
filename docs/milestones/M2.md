## How to try it
Once #28 is done I deploy it and post the URL on [#27](https://github.com/thomas-tahk/TTunes/issues/27). Then:
1. Open the URL at work, press **Play**. You hear the station.
2. **Sign in** (top right) with GitHub. Your panel appears under the player.
3. Paste a YouTube link or type a song name → pick it → **Play next**.
4. Send the URL to a friend. They press Play and hear the same song at the same point.

Watch for:
- The player is a small visible YouTube box (YouTube's rules: it can't be hidden) with the visualizer around it.
- When you skip, *your* screen changes at once; a friend follows within about 30 seconds.
- Your panel: Skip, the queue (Up / Down / Remove), Library (Delete → Undo), Trash (Restore), Activity, and Account (Export library, Sign out everywhere).

**Fixed along the way** (from the whole-milestone review and QA):
- The database schema now updates itself on each production deploy, safely if two run at once ([266106f](https://github.com/thomas-tahk/TTunes/commit/266106f), [5abdcc8](https://github.com/thomas-tahk/TTunes/commit/5abdcc8), [8f4d2d1](https://github.com/thomas-tahk/TTunes/commit/8f4d2d1)).
- Any open tab used to keep the free database awake all day. Now a tab only re-checks while it's playing (or it's your tab) ([033a183](https://github.com/thomas-tahk/TTunes/commit/033a183), [460c707](https://github.com/thomas-tahk/TTunes/commit/460c707)).
- The activity log kept YouTube titles forever (YouTube allows 30 days); it now stores only the video id ([5abdcc8](https://github.com/thomas-tahk/TTunes/commit/5abdcc8)).
- Sign out everywhere and Export library existed only as API calls; they now have buttons ([033a183](https://github.com/thomas-tahk/TTunes/commit/033a183)).
- Your Skip didn't update your own screen ([033a183](https://github.com/thomas-tahk/TTunes/commit/033a183)).
- An "Off air" tab never noticed the first song added; it now has **Check again**, and the browser no longer serves a 5-second-old copy ([d429323](https://github.com/thomas-tahk/TTunes/commit/d429323)).
- Station setup docs: [`station/README.md`](../../station/README.md).

**Known, not fixed:**
- A friend sees your skip up to ~30s later; a very short song can pass without their screen catching it. Kept to stay on free tiers.
- A tab that never pressed Play doesn't follow along until reloaded (keeps the free database asleep).
- The pooled-database migration test hasn't run (Docker couldn't pull the pooler image here). The first deploy proves it.

**Stuck:** none.
