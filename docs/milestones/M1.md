## How to try it
Follow the commands in the PR description (clone/pull, `brew install node yt-dlp ffmpeg`, double-click **Start TTunes**). Then:
1. Paste a YouTube song link in the box → check the card → **Queue last** (or Play now).
2. Drag an MP3 from Finder onto the page → **Queue last**.
3. Type a song name in the same box → press Enter → click the right match → **Queue last**.
4. Let it run. After those three, it should keep playing from your library on its own.

Watch for:
- The first time, your browser may need one click on ▶ (Safari blocks autoplay).
- The "is this the song?" preview on the card, in Safari.
- Whether the top-5 search results are actually the songs you meant.

**Fixed along the way:**
- First drop into an empty library started a random song before you chose, then played it twice — now nothing plays until you choose, and drop order is kept ([ec53476](https://github.com/thomas-tahk/TTunes/commit/ec53476)).
- Shuffle always replayed the previous cycle's last song second; queued songs could vanish; deleting everything left a ghost "now playing" ([#16 fixes](https://github.com/thomas-tahk/TTunes/issues/16)).
- Security: the server accepted requests from any website and any device on your wifi (any page could delete your library). It now only listens to your own Mac and checks where requests come from.
- Errors from yt-dlp are plain: "yt-dlp isn't installed — run: brew install yt-dlp", "That video is private or unavailable.", and otherwise a hint to run `brew upgrade yt-dlp` (an out-of-date yt-dlp is the most likely way this breaks over time).
- Library file is written safely (a power cut mid-save can't wipe your song list); seeking with odd ranges no longer drops the connection; leftover YouTube downloads are cleaned up.

**Known, not fixed:**
- Reloading the page forgets the queue (the library is kept). Fine for M1; say if it bothers you.
- Once in three runs, the player logged a second start of the same song. The shuffle logic itself was checked over 2000 simulated runs with no repeats; unclear if you'd hear it.

**Stuck:** none.

## Decisions that need you (most important first)
1. **Queue next/last when nothing is playing starts playing.** Built that way so it's never silent. Alternative: queue and wait for ▶.
2. **Only your Mac can reach TTunes.** Phone-on-wifi (a "later" item) will need a deliberate switch.
3. **"+ Queue" on the song that's playing queues it again** to play after the queue. Adding a song that is already playing from a link/drop/search never duplicates it.
4. **Typed search shows 5 results, always.** No "best match" auto-pick.
5. **Merge:** one PR, `m1-local` → `main`. You press Merge on GitHub (cloud sessions never push to main).

Every other interpretation is in [`docs/questions/M1.md`](../questions/M1.md).
